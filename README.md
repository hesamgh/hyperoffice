# هایپرآفیس — HyperOffice

لندینگ پیج حرفه‌ای برای معرفی خدمات طراحی سایت و توسعه وب.

## تکنولوژی‌ها

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**

## اجرای پروژه

```bash
npm install
npm run dev
```

سایت روی [http://localhost:3000](http://localhost:3000) اجرا می‌شود.

## بیلد برای Production

```bash
npm run build
npm start
```

## SEO

- Metadata کامل (Open Graph, Twitter Cards)
- JSON-LD Structured Data (Organization, WebSite, FAQ, ProfessionalService)
- Sitemap و Robots.txt
- زبان فارسی با `lang="fa"` و `dir="rtl"`
- کلمات کلیدی: طراحی سایت، توسعه وب، Next.js
